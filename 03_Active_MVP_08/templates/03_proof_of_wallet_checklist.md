## 1. The Validation Gate (Pass / Fail)

- [ ] **Footprint Test:** Did a real human say they are paying money or actively seeking a tool for this problem within the last 90 days? *(Must cite verbatim URL & quote)*
- [ ] **The 10% Wedge Test:** Can this problem be solved by stripping away 90% of a bloated SaaS product and delivering just the core 10% value in <3 seconds?
- [ ] **Zero-API Feasibility:** Can this tool run 100% locally in the browser (HTML/JS/LocalStorage/Web Worker) without needing paid backend APIs (OpenAI/Anthropic/AWS)?
- [ ] **Distribution Clarity:** Does a dedicated subreddit, forum, or marketplace already exist with 10,000+ active users searching for this topic?
- [ ] **Pricing Leverage:** Can this be sold as a clean $9 to $19 one-time lifetime license instead of an annoying monthly subscription?
