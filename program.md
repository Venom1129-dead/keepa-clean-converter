# Program Directive: AI Autonomous Income & Trading Factory

## 1. Core Mission
Build, validate, and scale autonomous software tools, algorithmic testing engines, and digital micro-assets that solve painful, high-intent problems:
$$\$1/\text{day} \longrightarrow \$10/\text{day} \longrightarrow \$100/\text{day}$$

---

## 2. Locked Operational Rules
1. **The Autonomous Execution Loop:**
   - Antigravity must never stall or halt between tasks. Keep executing through the roadmap in a continuous loop until the milestone is verified complete.
   - When one asset is verified and deployed, immediately start the next asset in the queue.
2. **User Interruption Policy:**
   - ONLY pause to ask the user when an explicit user-side action or decision is needed (e.g. entering a payment method, private credentials, or high-level direction).
   - Never interrupt the user for technical steps that the AI can execute and verify autonomously.
3. **The 24-Hour Production Invariant:**
   - Every digital income asset or trading strategy must go from research spec to working code and deterministic verification within hours, not days.
4. **Zero-Capital & Zero-SaaS Expense:**
   - All tools, APIs, hosting (GitHub Pages), and backtest data must utilize free, institutional public archives ($0.00 upfront).
5. **Universal Portability:**
   - Zero hardcoded personal paths. 100% relative paths. The entire workspace must run on any machine or drive.
