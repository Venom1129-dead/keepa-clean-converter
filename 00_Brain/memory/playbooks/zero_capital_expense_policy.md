# Zero-Capital & Zero-Expense Operating Policy
- **Core Directive:** $0.00 Out-of-Pocket Investment. No upfront fees, no monthly software subscriptions, no paid API tokens.
- **Revenue Model:** Pure revenue-share only (platforms deduct standard merchant fees only *after* customer money is received).

---

## 1. Hosting & Infrastructure ($0.00 Cost)
- **GitHub & GitHub Pages:** 100% Free. Unlimited public repositories, static web hosting, and SSL certificates at $0.00 cost forever.
- **Local Client-Side Architecture:** Tools run 100% in the user's browser (HTML5, Web Workers, PapaParse, LocalStorage). 0 backend cloud servers, 0 database hosting bills.
- **AI Agent Execution:** Local models and agent sessions via Antigravity, OpenCode CLI, and local python verification scripts. $0.00 API expenses.

---

## 2. Sales & Distribution Platforms ($0.00 Upfront Cost)
- **Gumroad:** $0.00 setup, $0.00 monthly fee. Gumroad charges a 10% fee only when a customer actually pays you. If you make $0, you owe $0.
- **Lemon Squeezy:** $0.00 setup, $0.00 monthly fee. Standard transaction fee deducted only upon successful customer checkout.
- **Notion Template Gallery:** 100% Free. Duplicating and sharing templates with Notion users costs $0.00.
- **Microsoft Edge Add-ons:** 100% Free developer account ($0 registration fee).
- **Reddit & Community Outreach:** 100% Free organic distribution.

---

## 3. Strict Guardrails
1. Never suggest or purchase paid domains, paid server hosting (AWS/Vercel Pro/Heroku), or paid tools.
2. If any platform ever requires an upfront fee (such as Chrome Web Store's $5 registration fee), bypass it immediately in favor of 100% free distribution (Edge Add-ons & Gumroad direct download).
3. Maximize pure take-home margin: Gross income flows directly into the user's account without recurring liabilities.
