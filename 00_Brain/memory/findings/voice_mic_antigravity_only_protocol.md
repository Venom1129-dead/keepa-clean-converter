# Voice Protocol: Antigravity-Only Mic Guard & Sleep State
- **Rule:** Never mute the Windows system microphone. Only mute Antigravity's attention and responses.
- **User Intent:** The user wants to talk to family, friends, phone calls, or game on Discord without Antigravity listening, transcribing, or interrupting.

## Commands:
1. **"Antigravity Mute Down" (or "Antigravity Mode Down"):**
   - Antigravity immediately enters `SLEEP / MUTED` mode.
   - Behavior: Total silence. Do not reply, do not process background chatter, do not interrupt.
2. **"Antigravity Listen Up":**
   - Antigravity exits `SLEEP` mode and resumes active conversation.
   - Behavior: Acknowledges with a brief *"I'm listening"* and awaits instructions.
