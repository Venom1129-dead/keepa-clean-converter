## 2. Product Features & Wedge
- **100% Manifest V3 Compliant:** Runs locally inside the browser. Zero telemetry, zero external network requests.
- **Instant Meta & Pixel Validation:** Checks Title (<60 chars) and Meta Description (<160 chars) against Google SERP truncation thresholds.
- **Canonical & Heading Hierarchy:** Flags missing or mismatched canonical URLs, detects missing H1s or duplicate H1s.
- **JSON-LD Schema Extractor:** Parses schema script tags, displays validated `@type` objects (Product, Organization, FAQ, Article), and catches malformed JSON syntax.
- **1-Click Client Export:** Generate ready-to-send Markdown client reports or summary CSV files for freelancing deliverables and proposals.
